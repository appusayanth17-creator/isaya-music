# 🎵 ISAYA Music

**ISAYA Music** is a modern web-based music player designed for an immersive and convenient music-listening experience.

🎧 **Live App:** https://isayamusic.netlify.app/

## ✨ Features

* 🎵 Online music player
* ▶️ Play, pause and control music
* ⏭️ Next and previous track controls
* 🔊 Volume controls
* 📱 Responsive web interface
* 🎨 Clean and modern music-player design
* 📂 Music playlist organization
* 🔎 Easy music discovery and navigation
* 🌐 Web-based — no installation required
